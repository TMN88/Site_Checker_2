# Изменения

## 2.0.0-local.6 — 2026-10-29

- На пользовательском OpenWrt 25.12.5 подтверждена причина отказа трёх вкладок: jq 1.8.1 собран без Oniguruma. Убраны regex-функции из обработки диагностики, соединений и чтения контроллера Podkop. Замена пакетов не нужна.
- Сохранены очистка управляющих символов, маскирование секретов и проверка адреса контроллера.
- Ошибка обработки задания больше не называется отменой пользователя; несовместимость jq имеет отдельное сообщение.
- Проверка сборки запрещает возврат regex-зависимости. Исправленные фильтры успешно обработали настоящие сохранённые ответы Forkozz на роутере. Полный повторный запуск после установки проверяется отдельно.

## 2.0.0-local.5 — 2026-10-29

- Сплошная мягкая розовая заливка активной вкладки в обеих темах.
- «Проверить сейчас», «Отменить» и «Настройки» в одной строке, настройки выровнены справа.
- Диагностика показывает, что проверялось, статус, источник и полученные значения: DNS, FakeIP, версии, ядро, серверы и время ответа, если они предоставлены установленным приложением.
- Вместо проверки маршрута — «Сайты сейчас» и «Соединения». Снимки только по нажатию через существующие API Forkozz/Forkop/Podkop. Настройки обходчиков не меняются.
- Ошибки API отличаются от пустого списка; ограничен размер ответа, секретные поля отбрасываются. Обновлены ACL, установка, удаление и браузерные проверки.

## 2.0.0-local.4 — 2026-10-29

- Исправлены чекбоксы и поля настроек: LuCI воспринимал disabled=false как присутствующий HTML-атрибут и блокировал ввод. Снятые галочки теперь сохраняются корректно.
- Браузерная проверка повторяет настоящую обработку атрибутов LuCI, проверяет сохранение выбора, скрывающую чекбоксы тему и режим только чтения.
- Диагностика и маршрут используют единый детектор установленного Podkop/Forkop/Forkozz. Конфигурации и файлы .control сами по себе больше не считаются установленными приложениями.
- Проверяются исполняемые компоненты, служба и библиотеки. Установленные пакеты и управляемый Forkozz имеют приоритет над остатками ручной установки. Настоящий конфликт показывает названия найденных приложений.
- Добавлены семь проверок обнаружения, включая старые конфигурации всех трёх приложений и неполную установку.

## 2.0.0-local.3 — 2026-10-29

- По последнему указанию пользователя полностью убраны резервирование и перенос настроек первой версии. Она удаляется вместе с конфигурацией после проверки версии 2; постоянный backup под /root не создаётся.

- Исправлена ошибка установщика: umask 077 закрывал каталог интерфейса и статические файлы, вызывая HTTP 403 при загрузке overview.js.
- Публичные каталоги теперь создаются с 755, файлы — с 644. Обновление также исправляет старый каталог приложения с правами 700.
- Конфигурация остаётся 600 в каталоге 700, резервные копии сохраняют закрытый доступ.
- Добавлены Linux-проверки свежей установки и обновления: настоящий HTTP-сервер от nobody воспроизводит 403 на старых правах и получает 200 после исправления.

## 2.0.0-local.2 — 2026-10-29

- По уточнению пользователя установщик заменяет найденную первую версию после успешной проверки версии 2.
- Старые компоненты и конфигурация копируются с проверкой SHA-256 в постоянный backup под /root.
- Добавлены точный список старых файлов, перенос доступных UCI-настроек и приоритет существующих настроек версии 2.
- Поддержан известный пакет luci-app-sitecheck: проверка файлов/пробного удаления и отказ затрагивать посторонние пакеты.
- При ошибке до переключения первая версия остаётся на месте. При сбое после переключения восстанавливаются её файлы.
- Добавлены адресные и Linux-тесты полного установщика на изолированной файловой модели.

## 2.0.0-local.1 — 2026-10-29

- Реализованы ручные фоновые задания, пул curl, блокировки повторного запуска и отмена.

- Добавлены LuCI JavaScript, RPC ACL, три вкладки, две темы и мобильная компоновка.
- Реализованы нативные адаптеры Podkop, Forkop 2.0 и Forkozz, нормализация статусов и безопасное unknown.
- Подключён настоящий анализ правил установленного Forkozz. Для Podkop/Forkop — явное ограничение.
- Собраны самодостаточный установщик, проверка SHA-256, резервное копирование/откат своих файлов и отдельное удаление.
- Добавлены заготовка SDK-пакета, Linux workflow, проверки backend и проверка интерфейса в браузере.
- Проект сохранён в D:/AI/GPT_Codex/Site Checker 2.0. Исходная копия на C: сохранена.
- Это локальная сборка: публикации и испытаний на реальном OpenWrt не было.
