# Источники и права

Собственный код Site Checker 2.0 опубликован в локальном дереве под MIT. Сторонние исходные функции и бинарники в установочный файл не включены.

- **TMN88/Site_Checker** — исходный проект, список сервисов и модель пользовательских настроек.
- **StressOzz/Zapret-Manager** — профиль HTTP-проверки из _test_prepare_urls и _si_sites; используется самостоятельно написанная реализация этого поведения.
- **itdoginfo/podkop** — внешние нативные диагностические команды; исходники в установщик не копируются.
- **ushan0v/forkop** — внешние нативные JSON-команды Forkop 2.0; исходники в установщик не копируются.
- **yandexru45/netshift / Forkozz в Zapret Manager** — внешние нативные команды и установленный netshift.uc. Собственный backend вызывает только diag и route существующего модуля. Он не устанавливает, не изменяет и не распространяет модуль.
- **TMN88/youtube-watchdog** — цветовые ориентиры интерфейса. Новые стили ограничены классом sc2.

Точные изученные commit и пути указаны в SOURCES.md. MIT корневого проекта не изменяет права на перечисленные внешние проекты. При будущем прямом переносе их кода необходимо отдельно проверить лицензию и сохранить требуемое авторство.
