# Проверка local.6 на настоящем роутере

29.10.2026, с разрешения пользователя установлена 2.0.0-local.6 на домашний OpenWrt 25.12.5 / aarch64. Установщик проверен по SHA-256: 8ef18941c743b4bfb39265437a1cf9405fb870247a54d2194ad74b42de615cb0.

Подтверждённая причина прежнего отказа: системный jq 1.8.1 собран без Oniguruma. Нативные ответы Forkozz корректны; local.5 падала при вызове regex-функций jq. В local.6 они заменены переносимыми операциями. Пакеты jq и Forkozz не менялись.

После установки все задания запущены через настоящий ubus RPC Site Checker:

| Задание | Полученный результат |
| --- | --- |
| Диагностика | done, ok=true, Forkozz, 7 проверок, 0 проблем |
| Сайты сейчас | done, ok=true, 45 текущих соединений |
| Соединения | done, ok=true, 45 текущих соединений |
| Сайты | done, ok=true, 8 выбранных сайтов: 7 доступных, chatgpt.com вернул HTTP 403 |

HTTP 403 chatgpt.com — ответ сервиса на запрос с роутера; он отображается как неопределённый результат и не означает сбой задания или доказанную блокировку.

Во всех четырёх журналах задания после запуска ноль байтов ошибок. overview.js и style.css доступны по HTTP 200 и побайтно совпадают с опубликованной сборкой. Хеши настроек Site Checker, network, dhcp, firewall, netshift и sing-box до и после обновления совпали. По родному get_sing_box_status ядро осталось запущенным, DNS остался настроен; значение enabled=0 существовало до обновления и не менялось. Перезагрузки и перезапуски сетевых служб не выполнялись. Установщик перезагрузил RPC Site Checker штатным reload rpcd.

Это проверка установки, настоящих backend-заданий, native Forkozz и HTTP-файлов интерфейса. Нажатия в браузере пользователя остаются ручной приёмкой после Ctrl+F5. Другие роутеры и установки Podkop/Forkop аппаратно не проверялись.
