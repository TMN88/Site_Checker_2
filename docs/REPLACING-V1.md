# Удаление первой версии при установке второй

По последнему указанию пользователя от 29.10.2026 первая версия удаляется полностью, без резервной копии и без переноса её настроек. Это отменяет прежний вариант миграции с резервированием.

## Что делает установщик

1. Проверяет известные пути первой версии и, при пакетной установке, состав пакета luci-app-sitecheck.
2. Устанавливает версию 2 и проверяет её файлы, настройки и регистрацию RPC.
3. После успешной проверки удаляет Lua-контроллер, страницу LuCI, три помощника, старое меню и UCI-конфигурацию первой версии.
4. Убирает известные остатки её конфигурации с суффиксами opkg/apk и пустой каталог её страницы.
5. Сбрасывает кэши меню LuCI.

Резервная копия первой версии не создаётся ни в /root, ни в /tmp. Старый выбор сайтов, включая UCI, не переносится. При новой установке используются настройки версии 2 по умолчанию; при обновлении уже существующая конфигурация версии 2 сохраняется.

Служебные файлы плана удаления содержат только пути и команды пакетного менеджера, а не содержимое старых файлов. Они находятся во временной папке установщика.

## Пакетная установка версии 1

Поддерживается известный пакет luci-app-sitecheck. Посторонние файлы в составе пакета блокируют удаление. opkg работает без autoremove и без принудительного удаления зависимостей. Для apk проверяется пробный план: удаление других пакетов запрещено. Общие зависимости, сетевые приложения и podkop-vpn-failover не удаляются. Старый install.sh --uninstall не вызывается.

## Ошибки

До подтверждения работы версии 2 первая версия остаётся на месте. При сбое установки выполняется временный откат только собственных файлов версии 2.

После начала окончательного удаления первой версии она не восстанавливается: резервной копии нет. Если пакетный менеджер сообщает ошибку удаления, рабочая версия 2 остаётся установленной, а установщик явно сообщает, что удаление первой версии не завершилось.

Постоянные копии под /root этим установщиком не создаются. Существовавшие до запуска резервные копии прежних установок этот сценарий не просматривает и не удаляет.

## Проверки

Адресные тесты проверяют отсутствие копирования старого содержимого, удаление конфигурации, допустимые файловые пути и пакетные сценарии. Linux-тесты запускают настоящий установщик с его архивом в тестовой папке: отсутствие постоянного backup, сохранение первой версии при отказе RPC и сохранение настроек уже существующей версии 2. Это модельные проверки, не результат реальной установки на OpenWrt.
